# Boatline

A modern boating editorial, community, and marketplace web platform featuring verified boat guides, certified dealer resources, live NOAA/NWS marine conditions, and community stories.

## Features

- **Editorial Field Guides**:
  - *10 Things to Check Before Buying a Used Boat* — In-depth pre-purchase inspection guide with technical checkpoints, cold start protocols, and hull inspection diagrams.
  - *How to Read the Water When Fishing Slows Down* — Complete biological, surface condition, sonar/CHIRP, and contour analysis field guide.
  - *The 10 Best Boats for Beginners* & *The Boat Buyer's Field Guide*.
- **Live NOAA/NWS Marine Conditions**:
  - Real-time weather, water temperature, tide reports, wind speed, wave height, and atmospheric pressure.
  - Searchable marine stations and automated updates.
- **Marketplace & Community**:
  - Boat marketplace preview with verified listings and valuation tools.
  - Mariner community dispatches with story submissions, photo uploads, and bookmarking.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
The application will start on `http://localhost:3000`.

### Production Build
```bash
npm run build
npm start
```
